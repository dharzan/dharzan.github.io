# AI Context

This repo is Dharsan Guruparan's engineer-first portfolio.

## Purpose

Show backend, full-stack, SDET / quality engineering, distributed systems testing, cloud, CI/CD, and AI-assisted engineering workflow experience without making the site feel like a toy or overbuilt demo.

## Rules

- Do not add a backend.
- Do not add a database.
- Do not add a CMS.
- Do not add auth.
- Do not add a contact form.
- Do not add fake progress bars.
- Do not add heavy animation or 3D systems.
- Keep the theme black, gray, and white.
- SDET work should be framed as engineering impact: test architecture, quality gates, backend validation, CI feedback, and distributed event reliability.
- AI is an accelerator, not the whole identity.

## Source of Truth

- Projects: `src/data/projects.ts`
- Skills: `src/data/skills.ts`
- Experience: `src/data/experience.ts`
- Contact links: `src/data/links.ts`

## Testing

Run `npm run lint` and `npm run build` before shipping. Run `npm run test:e2e` when Playwright browsers are installed.

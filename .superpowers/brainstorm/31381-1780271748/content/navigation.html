After the boot — how does navigation work?

This is the core UX decision. Choose the model that feels most natural for you.

A

Scroll-through sections

After boot, the terminal "outputs" each section as you scroll. Like a very long terminal session — About, Skills, Projects, Experience each appear as if the terminal is printing them live. The scroll drives the "output." Familiar UX, terminal skin on top.

B

Persistent command prompt

A real $ prompt stays at the top or bottom. You type (or click) commands: ls projects, cat about.md, open tripstream. Each command renders a section. Back button = terminal history. This is the deepest commitment to the metaphor.

C

Command nav + scroll within sections

A minimal nav bar shows commands: [about] [projects] [experience]. Clicking one "runs" it and jumps you to that section. Within sections, you just scroll. The command metaphor is visual/decorative but navigation is click-based and accessible.
